# SA-NSGA-III-AOVNS
Simulated Annealing Non-dominated Sorting Genetic Algorithm III with Adaptive Objective-oriented Variable Neighborhood Search，SA-NSGA-III-AOVNS, including NSGA-III framework, Adaptive Variable Neighborhood Search (AOVNS), Crossover and Mutation Operator, and Levy Flight.

## Introduction

First, the corresponding scheduling environment of MO-FAJSP-DM and DMO-FAJSP is established, which satisfies the constraints of nonlinear degradation, mixed maintenance (CBM & OM), and dynamic machine breakdown.

## Components

python ==3.8

numpy == 1.24.3

## Use

First deploy the project, configure the environment, and run main.py directly in your personal IDE.

## How to see the  results?

You can run the program to visualize the Gantt Chart and iterative curve after the end of the program.
